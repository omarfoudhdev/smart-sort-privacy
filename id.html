Singkatnya: Smart Sort tidak memiliki akun maupun server sendiri. Progres permainanmu tetap di ponselmu. Iklan, statistik, laporan error, dan pembelian ditangani oleh layanan Google, sesuai pilihan persetujuanmu.

1. Siapa kami

Smart Sort (paket Android com.fddev.smartsort) diterbitkan oleh FDDev.

Untuk pertanyaan atau permintaan apa pun tentang datamu: omar.foudh.dev@gmail.com. Kami membalas dalam 30 hari.

2. Data yang hanya disimpan di perangkatmu

Game menyimpan di ponselmu: level dan bintang, koin, nyawa dan booster, pengaturanmu (suara, musik, getar, mode buta warna), pembelian yang kamu miliki, dan ID instalasi acak yang dibuat oleh aplikasi.

Data ini tidak terhubung dengan nama, email, atau akun apa pun. Pencadangan Android dinonaktifkan untuk aplikasi ini: menghapus instalasinya akan menghapus semuanya.

3. Layanan Google yang digunakan game

  • Google AdMob (iklan) dan formulir persetujuan Google (UMP): ID iklan, informasi perangkat (model, versi Android, bahasa), alamat IP (lokasi perkiraan), dan interaksi iklan, untuk menampilkan dan mengukur iklan serta mencegah penipuan. Di EEA, Inggris, dan Swiss, formulir persetujuan muncul sebelum permintaan iklan apa pun; iklan hanya dipersonalisasi jika kamu setuju.
  • Firebase Analytics: peristiwa dalam game (level dimulai dan selesai, booster yang dipakai, hadiah, pembelian, iklan yang ditampilkan), ID instalasi acak, dan informasi perangkat, untuk memahami tingkat kesulitan dan meningkatkan game. Jika persetujuan diperlukan, pengukuran tetap nonaktif sampai kamu menyetujuinya.
  • Firebase Crashlytics: laporan crash dan error (kondisi perangkat, versi aplikasi, ID instalasi acak), untuk memperbaiki bug.
  • Firebase Cloud Messaging: token teknis perangkat, untuk mengirim notifikasi game (misalnya saat nyawamu sudah penuh kembali).
  • Google Play Billing: pembelian diproses oleh Google Play. Kami hanya menerima produk yang dibeli dan konfirmasinya, tidak pernah data pembayaranmu.

Layanan ini mengikuti aturan Google: Kebijakan Privasi Google · Cara Google menggunakan data · Privasi Firebase.

4. Mengapa kami menggunakan datamu (dasar hukum)

Untuk menjalankan game dan mengirimkan pembelianmu (pelaksanaan kontrak); untuk menampilkan iklan yang membiayai game gratis dan mengukur penggunaannya (persetujuanmu bila diwajibkan, selain itu kepentingan sah kami); untuk menjaga game tetap stabil dan aman (kepentingan sah).

5. Lama penyimpanan

Data di perangkatmu: sampai kamu menghapus instalasi game. Statistik Google Analytics: paling lama 14 bulan. Laporan crash: 90 hari. Pembelian disimpan oleh Google Play sesuai aturannya sendiri.

6. Pilihan dan hakmu

  • Persetujuan iklan: ubah kapan saja di dalam game: ⚙ → tombol gembok “Opsi privasi” (ditampilkan bila diwajibkan hukum).
  • ID iklan: setel ulang atau hapus di pengaturan Android (Google → Iklan).
  • Notifikasi: matikan di pengaturan Android aplikasi.
  • Hapus semuanya: hapus instalasi game.

Tergantung tempat tinggalmu (khususnya GDPR di Eropa dan UU PDP di Indonesia), kamu memiliki hak akses, perbaikan, penghapusan, pembatasan, keberatan, dan portabilitas. Tulis ke omar.foudh.dev@gmail.com; kamu juga dapat mengadu ke otoritas perlindungan data di negaramu.

7. Anak-anak

Smart Sort tidak ditujukan untuk anak di bawah 13 tahun dan kami tidak dengan sengaja mengumpulkan data mereka. Jika menurutmu seorang anak telah memakai game dengan cara yang melibatkan datanya, hubungi kami.

8. Keamanan

Data game disimpan di ruang penyimpanan pribadi aplikasi, yang diisolasi Android dari aplikasi lain. Komunikasi dengan layanan Google dienkripsi (HTTPS).

9. Perubahan

Kami akan memperbarui halaman ini jika cara game menangani data berubah. Tanggal di bagian atas menunjukkan versi yang berlaku.
